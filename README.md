# Шашки (Checkers)

## Описание проекта

Шашки (Checkers) — это классическая настольная игра, реализованная на C++ с использованием фреймворка Qt (версия 6.11.1). Проект предлагает три режима игры: против компьютера, для двух игроков на одном компьютере и по сети. Игра обладает интуитивным интерфейсом, анимацией ходов, системой таймеров, встроенным чатом и возможностью сохранения истории партий.

---

## Ключевые особенности

- Три режима игры:
  - 🤖 Против компьютера – сражение с игровым интеллектом, использующим алгоритм Minimax с глубиной 2.
  - 👥 На одном ПК – игра вдвоём за одним устройством.
  - 🌐 По сети – подключение к серверу, создание/вступление в комнаты, чат, автоматическое распределение цветов.

- Интерактивный игровой процесс:
  - Подсветка возможных ходов (зелёные точки для обычных, красные для рубок).
  - Анимация перемещения шашек.
  - Отображение таймера для каждого игрока (по 5 минут на партию в локальном режиме).
  - Счётчик побитых шашек.

- Сетевой функционал:
  - Встроенный сервер (порт 5555) и клиент.
  - Список доступных комнат с количеством игроков.
  - Общий чат внутри комнаты.
  - Автоматический старт при наборе двух игроков.

- Сохранение и история:
  - Возможность сохранить историю всех ходов партии в файл `checkers_game.txt` (в папке `Documents` пользователя).

## Системные требования

- ОС: Windows (также возможна сборка на Linux/macOS с соответствующими зависимостями).
- Зависимости: Qt 6.11.1 или новее (модули `core`, `widgets`, `network`).
- Компилятор: с поддержкой C++17 (MinGW, MSVC, GCC).
- Рекомендуемая среда разработки: Qt Creator, Visual Studio Code (с расширениями для C++ и CMake).

## Управление

### В режиме игры (на доске):
- Левая кнопка мыши (ЛКМ):
  - Клик по своей шашке → выделение (подсвечивается жёлтым).
  - Клик по доступной клетке (зелёная/красная точка) → выполнение хода.
- Кнопка `Выйти` – возврат в главное меню (или в лобби в сетевом режиме).
- Кнопка `Сохранить`– сохранение истории текущей партии в файл.
- Поле ввода чата (в сетевом режиме) – отправка сообщений сопернику.

### В главном меню:
- Клик по кнопкам для перехода к выбору режима или выхода из приложения.

### В меню выбора режима:
- Выбор одного из трёх режимов.
- Кнопка `Назад` для возврата в главное меню.

### В сетевом лобби:
- Создать комнату – создание новой игровой комнаты.
- Войти в комнату – присоединение к выбранной комнате из списка.
- Чат– общение с другими игроками.
- Назад – возврат в главное меню.

## Сборка проекта

Для сборки необходимы:
- Qt (версия 6.11.1 или выше) с установленными модулями `qtbase`, `qtnetwork`.
- Компилятор с поддержкой C++17.
- qmake.

Проект можно собрать несколькими способами.

### Сборка в Qt Creator (рекомендуемый способ для начинающих)

1. Установите Qt с официального сайта: https://www.qt.io/download  
   При установке выберите компоненты для вашего компилятора (MinGW или MSVC).

2. Запустите Qt Creator.

3. В главном меню выберите "Файл" → "Открыть файл или проект" (или нажмите `Ctrl+O`).

4. В диалоговом окне перейдите в папку с проектом и выберите файл `Checkers.pro`.

5. Qt Creator автоматически определит набор компиляторов (Kit). Выберите нужный (например, `Desktop Qt 6.11.1 MinGW 64-bit`) и нажмите "Настроить проект".

6. Нажмите зелёную кнопку "Запустить" (или `Ctrl+R`) в левом нижнем углу.

✅ Проект соберётся и сразу запустится. Все настройки сборки уже прописаны в `.pro` файле.


### Инструкция по сборке с использованием qmake

1. **Установка Qt**  
   Скачайте и установите Qt с официального сайта (https://www.qt.io/download). При установке выберите компоненты для вашего компилятора (MinGW или MSVC).

2. **Клонирование репозитория**
   ```bash
   git clone https://github.com/yourusername/checkers.git
   cd checkers
   ```

3. **Сборка через qmake**
   ```bash
   mkdir build
   cd build
   qmake ../Checkers.pro
   make
   ```
   Исполняемый файл (например, `checkers.exe` или `checkers`) появится в папке `build`.

4. **Запуск приложения (Windows)**
   ```bash
   ./checkers.exe
   ```


## Технические детали реализации

- Игровая логика – класс `GameLogic` (геймплей, правила, генерация ходов, проверка взятий, превращение в дамки).
- Игровой интеллект – используется алгоритм Minimax с глубиной 2 и эвристическую оценку позиции (учёт количества шашек, дамок, центра и продвинутости).
- Сетевой модуль – построен на `QTcpSocket` и `QTcpServer`, протокол сериализации через `QDataStream` (структуры `NetworkMove`, `BoardState`).
- Графический интерфейс– наследуется от `QWidget`, отрисовка через `QPainter`, анимация с использованием `QTimer`.
- Таймеры – реализованы на `QTimer` с интервалом 1 секунда.
- Сохранение истории – запись в текстовый файл с использованием `QFile` и `QTextStream`.
